# Task Tracker Full Stack

Day 1 setup for a portfolio project.

## Goal
Build a full-stack task management app with:
- React + TypeScript frontend
- FastAPI backend
- PostgreSQL database
- Docker containerization
- GitHub Actions CI

## Folder Structure
- `frontend/` - React app
- `backend/` - FastAPI app
- `docs/` - planning notes and diagrams
- `infra/` - Docker and deployment files

## MVP Features
- User registration and login
- Create, view, edit, and delete tasks
- Filter tasks by status

## First API Ideas
- `POST /register`
- `POST /login`
- `GET /tasks`
- `POST /tasks`
- `PUT /tasks/{id}`
- `DELETE /tasks/{id}`
