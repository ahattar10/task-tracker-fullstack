# Task Tracker Full Stack

[![CI](https://github.com/ahattar10/task-tracker-fullstack/actions/workflows/ci.yml/badge.svg)](https://github.com/ahattar10/task-tracker-fullstack/actions/workflows/ci.yml)

Day 1 setup for a portfolio project.

## Goal
Build a full-stack task management app with:
- React + TypeScript frontend
- FastAPI backend
- PostgreSQL database
- Docker containerization
- GitHub Actions CI

## Day 1 Scope
- Create the repo structure
- Define the MVP
- Write the initial project plan
- Prepare for backend and frontend work

## MVP Features
- User registration and login
- Create, view, edit, and delete tasks
- Filter tasks by status

## First API Ideas
- `POST /register`
- `POST /login`
- `GET /tasks`
- `POST /tasks`
- `PUT /tasks/{id}`
- `DELETE /tasks/{id}`
